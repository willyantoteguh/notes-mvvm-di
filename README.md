
# Basic Notes App for Android(Kotlin)

This is simple notes app that follows MVVM architectural design pattern.


## MVVM Architecture

Model View ViewModel (MVVM) is an architectural pattern which helps us to build an application by facilitating separation of development of User Interface (Activity or Fragment) from the development of the business logic or back-end logic (the data model).
